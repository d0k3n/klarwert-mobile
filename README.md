# Klarwert Mobile

**Klarwert** (German: "clear value") is a local-first portfolio analyzer for
Trade Republic CSV exports. This repository contains the Android app: the
Python engine from the original project has been ported to TypeScript and runs
100% on the device, wrapped in a Capacitor webview. No server, no telemetry,
your data never leaves the phone.

## What was ported

| Original (Python) | Mobile (TypeScript) |
|---|---|
| `portfolio/parser.py` | `src/csv.ts` (RFC 4180 parser, TR column detection, dedupe, classification) |
| `portfolio/engine.py` | `src/engine.ts` (FIFO, lots, P&L, TILG, knock-out detection, spending, income, derivatives) |
| `portfolio/performance.py` | `src/performance.ts` (XIRR via bisection, win/loss stats) |
| `portfolio/tax_report.py` | `src/tax_report.ts` (per-year disposals and dividends) |
| `portfolio/market.py` | `src/market.ts` (Finnhub quotes + Frankfurter FX, key stored on device) |
| `app.py` (Flask API) | `src/api.ts` (fetch interceptor serving the same `/api/*` routes in-memory) |
| `templates/`, `static/` | `web/` (same UI, adapted for Capacitor) |

The engine output is verified against the Python implementation: `tests/`
contains ported unit tests plus a full parity test that compares every
endpoint result against a reference dump of the original engine on a
903-transaction dataset (FIFO matches, tax reports, P&L, spending, income).

## Project layout

```
src/            # TypeScript engine (port of portfolio/)
web/            # frontend (index.html, dashboard.js, style.css, vendor/)
tests/          # node --test suite (unit + parity vs Python reference)
android/        # generated by Capacitor (gitignored)
```

## Requirements

- Node.js 20+ and npm
- JDK 17+ (the Android Studio bundled JBR works)
- Android SDK (platforms and build-tools; Android Studio installs these)
- A phone with USB debugging or an emulator to install

## Build the APK

```bash
npm install
npm run apk
```

The `apk` script bundles the TypeScript engine into `web/engine.js`, syncs the
web assets into the Android project and runs `gradlew assembleDebug`. If
`JAVA_HOME`/`ANDROID_HOME` are not set globally, set them first, for example
on Windows PowerShell:

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
```

The installable APK lands at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## Install on your phone (sideload)

1. Copy `app-debug.apk` to your phone (USB, cloud drive, whatever you like).
2. Open it from the Files app. Android asks to allow installing from unknown
   sources; accept for the app you used to open the file.
3. Open Klarwert, tap **Load CSV** and pick your Trade Republic export. The
   file is copied into the app's private storage and stays on the device.

Alternative via USB with adb:

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## Development

Run the tests (no Python needed, fixtures included):

```bash
npm test
```

Preview the frontend in a desktop browser (engine bundle required first):

```bash
npm run build:engine
npx serve web
```

In the browser the same code runs with localStorage instead of the native
filesystem, which is enough to exercise the UI before deploying to a device.

## CI/CD and GitHub Releases

GitHub Actions runs the tests and web build for pushes and pull requests to
`main`. Stable version tags such as `v1.1.0` trigger a signed Android build and
publish the APK and its SHA-256 checksum to GitHub Releases.

Production signing requires four repository secrets and a securely backed-up
Android keystore. See [docs/RELEASING.md](docs/RELEASING.md) for the one-time
setup and release procedure.

## Notes

- Debug builds are signed with the debug keystore and install directly. For
  Google Play you need a signed release build (`assembleRelease` plus your
  own keystore) and a Play developer account.
- Live prices (Finnhub) are optional. Enter your free API key in the app
  (Market section); it is stored only on the device via Capacitor
  Preferences. HTTP calls go through CapacitorHttp, so no CORS issues.
- "Klarwert" is an independent, unofficial tool not affiliated with or
  endorsed by Trade Republic.
